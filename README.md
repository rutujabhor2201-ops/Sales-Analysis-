\# Sales Data Analysis



\## Project Overview



This project performs an analysis of sales transaction data using Python, Pandas, and Matplotlib.



The objective is to analyze sales performance, identify the top-selling product and best-performing region, and present the results through visualizations.



\## Dataset



The project uses the provided `sales\_data.csv` dataset containing 100 sales transactions.



The dataset includes:



\- Date

\- Product

\- Quantity

\- Price

\- Customer\_ID

\- Region

\- Total\_Sales



\## Technologies Used



\- Python

\- Pandas

\- Matplotlib

\- CSV

\- PowerShell
